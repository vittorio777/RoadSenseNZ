# RoadSense

An interactive frontend prototype for practising driving decisions on New Zealand roads.

[Live Demo](https://roadsense-nz.vercel.app/) · [Implementation, setup, and testing](road-master/README.md)

Learner drivers can explore practice locations, watch road scenarios, choose an answer, and read the explanation.

![RoadSense driving scenario](docs/assets/scenario-preview.png)

Built with React, TypeScript, Vite, Tailwind CSS, MapLibre GL, Canvas, and SVG. Tests use Vitest and React Testing Library.

The practice app is in `road-master/`; the promotional site is in `docs/`. This portfolio prototype contains a small set of demo scenarios, with browser-local progress and no account system.
